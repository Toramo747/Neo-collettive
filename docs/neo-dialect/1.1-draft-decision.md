# neo-dialect/1.1-draft decision

Status: **NO_DRAFT_NEEDED**.

Reviewed: 2026-09-27.

## Decision

No `neo-dialect/1.1-draft` schema or runtime implementation is created at this stage.

The reason is evidence, not convenience:

- point 1-bis produced 12 complete Arena sessions across collaborativo, scettico, confuso and ostile scenarios;
- model failures were generation-layer problems, not protocol gaps;
- the only recurring dialogue-level observation was `clarification_overloaded_into_counter` in 3/3 confused sessions;
- point 2 established that A2A already provides clarification through Messages and `TASK_STATE_INPUT_REQUIRED`;
- point 3 therefore admitted **0 numbered RFCs**.

Creating a 1.1 draft with no accepted semantic change would manufacture protocol churn without anything meaningful to test.

## Production protection

The following remain unchanged:

- `docs/neo-dialect.md`
- `schemas/neo-dialect/1.0/**`
- `neo_dialect.py`
- the public `/neo-dialect/1.0` contract

No 1.1 draft is promoted, advertised, negotiated or served publicly.

## Activation gate for a future 1.1-draft

A future `neo-dialect/1.1-draft` may be opened only when at least one numbered RFC has passed the RFC admission rule and is explicitly approved for Arena experimentation.

That RFC must have:

1. recurring DIALECT evidence;
2. no equivalent A2A primitive;
3. a proposed JSON schema;
4. 1.0 compatibility analysis;
5. security analysis;
6. Critic objections;
7. a measurable hypothesis for A/B testing.

Only after that gate is satisfied should version negotiation be added to an Arena-only draft.

## Version negotiation rule for the future

When a real 1.1 draft exists:

- A2A remains authoritative for transport/protocol-version negotiation;
- neo-dialect version selection must be treated as extension/application metadata above A2A;
- `HELLO` may advertise supported dialect versions;
- `CAPABILITIES` may confirm the selected dialect version;
- fallback to `neo-dialect/1.0` or plain A2A must be deterministic;
- production 1.0 remains untouched until Andrea explicitly approves a specification change.

These are design constraints, not an active 1.1 implementation.

## Consequence for point 5

The requested A/B test `1.0 vs 1.1-draft` is **not meaningful yet** because there is no accepted semantic delta.

Running an A/B test between two identical protocols would only measure model/runtime noise.

Therefore point 5 should remain blocked until a real RFC produces a draft with a falsifiable behavioral difference.

## Current conclusion

**NO_DRAFT_NEEDED**

neo-dialect/1.0 remains the only active dialect version.

This is a successful outcome of evidence-gated protocol evolution: no version is created merely to satisfy a roadmap step.
