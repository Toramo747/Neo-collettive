# October 2026 end-to-end same-query matched context audit

Protocol committed before the first query of 2026-10-01 through 2026-10-09 00:00 UTC. It uses the four fixed domains and query genes from August PR232, no selection or mutation based on the October search results. Baseline and shadow run over the **same in-memory responses** to precisely sixteen HN Algolia queries (4 topics x 4 suffixes) with 30 maximum hits each, using the same min relevance gate, existing stage diagnostics, supply/vendor, buyer voice, commercial-family and demand tag logic.

This is an actual **topic-targeted source retrieval** unlike PR237's source-context retrieval with counterfactual topic scoring. Both arms share provider, prompts, time window and exact results; **context cannot improve retrieval under this design**. The experimental `source_context` variable is assigned from public HN parent story titles only. It flags content already accepted by the frozen classifier when it originates from a known job-seeking, hiring or Show HN thread. Unknown sources are never silently rejected or treated as buyers; neither are known categories automatically vetoed. No new buyer evidence is claimed.

Success of this instrument means: all provider queries succeed, scorer and diagnostic stage accounting agree, baseline has at least 8 relevant hits and at least one distinct signal thread for description, and added source-context review notes change **zero** labels, signals, precision or genome parameters. This is an integrity/evidence-coverage check, not an uplift claim. Weak baseline, missing signals or source errors produce **inconclusive** even when regression tests pass. No unreviewed source-context annotation is proof of error or demand.

Outputs contain aggregate totals/contexts only, no public comment text, HN IDs, URLs or actual query strings. Raw data exist transiently in the CI memory only. There are no human labels, no paid API, no independent or confirmed buyer-demand evidence, no promotion, no main merge, no Render deploy, no changes to memory, commercial gate/thresholds, price caches or production model.

Follow-up requires external independent human adjudication of candidate errors and another preregistered study with an actual new model or ranking intervention; a review-only feature cannot by itself yield higher signal discovery, so no promotion should follow from identical scores.
